IMPORTANT:

DESIGN DIRECTION:

Create a premium urban / industrial / athletic aesthetic.

Overall feeling:
STRENGTH + MOVEMENT + DISCIPLINE + ENERGY + COMMUNITY

Visual direction:
- Dark charcoal / black foundation
- Strong neutral tones
- One distinctive premium accent color
- Industrial-inspired textures used subtly
- Bold athletic typography
- Large cinematic gym photography
- Strong geometric layouts
- High contrast
- Editorial-style compositions
- Premium gradients used sparingly
- Clean modern UI
- Sophisticated spacing
- Smooth motion

The railway identity should be subtle:
- thin line elements
- directional movement
- track-inspired dividers
- linear visual motifs
- subtle motion suggesting forward movement

DO NOT use:
- cartoon trains
- train icons everywhere
- railway-station graphics
- childish industrial graphics
- cheesy fitness clichés
- excessive rounded cards
- generic template layouts
- excessive neon colors
- AI-looking repetitive sections

The website should feel like a premium modern fitness club located in Richmond, BC.
